# Filesystem Types

## Native Linux Filesystems
- ext3
- ext4
- btrfs
- squashfs

---

## Filesystems from Other Operating Systems

### Windows
- ntfs
- exfat
- vfat

### macOS
- hfs
- hfs+

### Other UNIX Systems
- xfs (SGI)
- jfs (IBM)

---

## Legacy Filesystems
- fat

Linux supports many legacy filesystems for compatibility.

---

## Network Filesystems
Network filesystems allow part or all of the filesystem to reside on a remote machine.

Examples include:
- ceph
- lustre
- openafs
